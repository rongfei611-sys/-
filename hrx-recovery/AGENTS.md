# HRX Recovery 开发约束

本目录为2026-11-17重新建立的独立恢复基线，不是原V19.5源码。原V001–V014、原测试和确认HTML缺失；不得声称其已恢复或哈希一致。本目录的V001起点只能用于新数据库，不得覆盖旧系统。

所有业务身份来自验证的OIDC/JWT；默认拒绝，所有动作必须再次检查资源范围/职责分离/版本/审计/幂等。应用账号不能拥有表、BYPASSRLS或权限写接口。价格单独授权，隔离文件不得下载，文件与业务对象绑定。

不得自动批准角色、采购、付款、库存过账或质量放行。没有真实数据必须显示暂无数据/未配置。测试数据仅在隔离库使用TEST标记，不进入生产迁移。原视觉基线缺失，当前UI只能描述为参照截图重建。

开发后执行 npm ci/test/build 与脚本 verify-isolated.sh；数据库/浏览器/扫描测试缺环境时写清跳过，不将默认mvn成功冒充集成通过。更新验证记录与缺失清单。

代码放挂载仓库、按阶段Git提交并生成带SHA256清单的包。不把仅存于临时环境的路径称为用户已收到的交付。公开推送需用户对公开源码作明确确认；不要默认合并主分支。
