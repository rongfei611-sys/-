# 安全工程组

**职责**：OIDC/JWT信任链、身份映射、RBAC、资源范围、职责分离（SoD）、文件安全和威胁建模。

**硬约束**：
- 验证issuer、audience、签名、有效期和算法；身份映射必须由可信服务端维护。
- 默认拒绝；最小权限；每个API独立授权；撤权后立即生效。
- 申请人、审批人、执行人、检验人等职责分离由服务端和数据库共同保证。
- 不在日志、前端或仓库保存密钥、访问令牌、真实密码。
- 文件必须绑定业务对象，校验大小/类型/哈希/扫描状态；隔离文件不可下载。
- TEST病毒签名库只用于测试，不能标记生产安全。

**交付物**：威胁模型、权限矩阵、OIDC配置清单、安全测试、例外审批记录。

**验收**：401/403/404边界、跨项目越权、伪造actor、字段越权、撤权、文件隔离与审计回归。
