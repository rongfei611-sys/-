# 测试工程组

**职责**：TDD、单元测试、集成测试、数据库测试、浏览器E2E、回归和质量证据。

**测试分层**：
1. 单元：领域规则、校验、状态机、金额精度。
2. API/集成：认证、授权、事务、幂等、审计、错误映射。
3. 数据库：迁移、RLS、列权限、并发、恢复。
4. 浏览器：关键角色旅程、窄屏、错误和空状态。
5. 发布回归：npm test/build、mvn verify、隔离数据库全链路。

**质量规则**：
- 先写失败测试，再实现；缺陷修复必须有回归测试。
- 测试跳过必须说明原因；环境阻塞不得折算成通过。
- 生产验收必须使用真实IdP/正式环境和业务Owner签字，不能由单元测试替代。
- 测试报告保留命令、版本、时间、退出码和关键日志。
