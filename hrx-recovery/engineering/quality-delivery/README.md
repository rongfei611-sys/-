# 统一质量验收与交付中心

**职责**：独立汇总研发证据、审查PR、执行发布门禁、生成版本和交付记录。

**必须检查**：
- 需求与验收标准是否完整
- API/数据库/权限/审计是否同步
- 自动化测试和真实集成测试是否区分
- 代码审查是否完成，是否存在未关闭高危问题
- 迁移、部署、回滚、备份恢复是否有说明
- 版本号、变更清单、Manifest、SHA-256是否一致
- 已知限制和生产阻塞是否公开记录

**状态定义**：
- PASS：有可复现的实际测试证据
- FAIL：测试失败或门禁不满足
- BLOCKED：依赖/环境/权限缺失，未能执行
- NOT RUN：尚未运行
- ACCEPTED：业务Owner完成真实场景验收

**规则**：CI通过不等于生产就绪；所有P0门禁通过且业务Owner验收后才允许生产发布。
