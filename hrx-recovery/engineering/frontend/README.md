# 前端研发组

**职责**：React/Vite页面、路由、表单、状态管理、交互反馈和响应式体验。

**硬约束**：
- 只展示服务端授权返回的数据；无数据、无权限、未接入必须区分。
- 不用静态演示数字冒充真实经营数据。
- 不在客户端承担安全授权；隐藏按钮不等于后端授权。
- 所有写操作显示提交中、成功、失败、冲突和重试状态。
- 页面必须覆盖桌面和窄屏主要流程；键盘可操作并有可读标签。

**交付物**：组件/页面、交互测试、浏览器E2E、截图证据、API错误处理说明。

**验收**：npm ci、npm test、npm run build通过；关键用户旅程在浏览器真实运行；API 401/403/404/409/422状态显示正确。
