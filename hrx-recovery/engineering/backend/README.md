# 后端研发组

**职责**：Java 21、Spring Boot、REST API、领域服务、事务、幂等、审计和错误模型。

**硬约束**：
- 服务端重新验证身份、资源范围、角色和职责分离，不信任客户端actor/user/project ID。
- 写接口必须有事务边界、幂等策略、乐观并发和审计。
- 失败响应不得留下部分业务写入；MVC错误也必须验证回滚。
- 不暴露未授权字段、原始价格、文件存储路径或内部异常。
- 企业OIDC缺失时默认拒绝，不允许开发假登录绕过。

**交付物**：Controller/Service/Repository、API契约、单元/集成测试、迁移影响说明。

**验收**：mvn clean verify通过；真实数据库测试单独标明；越权、重复提交、并发冲突、SoD和事务回滚均有测试。
