# DevOps组

**职责**：Git分支策略、GitHub Actions、构建环境、部署、监控、依赖和供应链治理。

**分支策略**：
- 功能分支：`feature/<issue>-<topic>`
- 缺陷分支：`fix/<issue>-<topic>`
- 治理分支：`governance/<topic>-YYYYMMDD`
- 发布分支/标签由交付中心按版本计划创建。
- 禁止直接推送受保护分支；禁止强制推送和删除受保护分支。

**CI**：PR必须运行隔离验证；工作流使用最小权限、固定运行环境和受控Action版本；失败阻断合并。

**交付物**：工作流、部署脚本、运行手册、监控与告警、依赖审查和恢复方案。
